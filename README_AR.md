# تطبيق مدرسة LearnToBe تعلم لتكون (Laravel)

نظام ويب لرصد درجات الطلاب:
- **لوحة الإدارة:** تضيف المدرسين، وتكلّف كل مدرس بشعب ومواد، وتدير الصفوف والشعب والطلاب والمواد وعناصر الدرجة، وتتابع نسبة الرصد، وتنزّل الدرجات بملف Excel.
- **بوابة المدرس:** يدخل كل مدرس باسم مستخدم وكلمة مرور خاصة به، ولا يرى إلا الشعب والمواد المكلّف بها. يرصد الدرجات وتُحفظ كل خانة تلقائياً.

## ما يحتويه هذا المجلد

هذه ملفات التطبيق فقط، تُنسخ فوق مشروع Laravel جديد:

| المسار | المحتوى |
|---|---|
| `app/Models` | النماذج: المستخدم، الصف، الشعبة، المادة، الطالب، التكليف، عنصر الدرجة، الدرجة |
| `app/Http/Controllers/Admin` | لوحة الإدارة |
| `app/Http/Controllers/Teacher` | بوابة المدرس |
| `app/Services` | منطق الكشف، واستيراد الطلاب من Excel، وتصدير الدرجات |
| `database/migrations` | الجداول |
| `database/seeders` + `database/data/students.json` | البيانات الأولية: 16 صفاً، شعبة لكل صف، 866 طالباً، المواد، عناصر الدرجة، حساب الإدارة |
| `resources/views` | الواجهات (عربية، من اليمين لليسار) |
| `public/css`, `public/js`, `public/images` | التصميم، والحفظ التلقائي، وشعار المدرسة |
| `lang/ar` | رسائل التحقق بالعربية |

## التثبيت

يحتاج: PHP 8.2 أو أحدث، وComposer، وقاعدة بيانات MySQL أو SQLite.

```bash
# 1) مشروع Laravel جديد (الإصدار 11 أو أحدث)
composer create-project laravel/laravel learntobe-grades
cd learntobe-grades

# 2) انسخ محتويات هذا المجلد فوق المشروع واستبدل الملفات المكررة
#    (bootstrap/app.php و routes/web.php و app/Models/User.php وملف جدول users)

# 3) مكتبة Excel للاستيراد والتصدير
composer require phpoffice/phpspreadsheet
```

عدّل ملف `.env`:

```env
APP_NAME="دفتر رصد الدرجات"
APP_LOCALE=ar
APP_TIMEZONE=Asia/Gaza

# MySQL مثلاً (أو اترك SQLite الافتراضي للتجربة)
DB_CONNECTION=mysql
DB_DATABASE=learntobe_grades
DB_USERNAME=root
DB_PASSWORD=

# حساب الإدارة الأول
ADMIN_USERNAME=admin
ADMIN_PASSWORD=اكتب_كلمة_مرور_قوية
```

ثم:

```bash
php artisan key:generate        # إن لم يكن المفتاح موجوداً
php artisan migrate:fresh --seed
php artisan serve
```

افتح `http://127.0.0.1:8000` وادخل بحساب الإدارة. **غيّر كلمة المرور فوراً** من رابط «كلمة المرور» أعلى الصفحة.

## طريقة الاستخدام

1. **عناصر الدرجة:** راجعها أولاً. القيم المبدئية هي الشهري الأول 20، والشهري الثاني 20، والمشاركة 5، والواجبات 5.
2. **المواد:** أضف أو احذف حسب مواد المدرسة.
3. **الصفوف والشعب:** أُنشئت تلقائياً من كشف الطلاب حسب نظام المدرسة:
   - من البستان إلى الخامس: شعبة مختلطة واحدة لكل صف.
   - من السادس فما فوق: شعبة **إناث (صباحي)** وشعبة **ذكور (مسائي)**، ويوضع كل طالب في شعبته حسب جنسه.

   لإعادة تطبيق هذا التقسيم على قاعدة بيانات موجودة: `php artisan school:split-sections`. الأمر ينقل الطلاب حسب الجنس، وينسخ تكليف المدرس من الشعبة القديمة إلى الشعبتين الجديدتين، والدرجات لا تتأثر.

   لإضافة شعبة أخرى (مثل «إناث 2»): أضفها من «الصفوف والشعب»، ثم من صفحة الطلاب حدّد الطلاب واضغط «نقل». النظام لا ينقل طالباً إلى شعبة جنسها مختلف.
4. **المدرسون:**
   1. اضغط «إضافة مدرس»، واكتب اسمه واسم المستخدم وكلمة المرور.
   2. تنتقل تلقائياً إلى صفحة «الشعب والمواد». اختر المواد والشعب، فيُنشأ كشف لكل شعبة مع كل مادة.
   3. أرسل للمدرس رابط الموقع واسم المستخدم وكلمة المرور.
5. **المتابعة:** الصفحة الرئيسية للإدارة فيها جدول بكل الشعب مقابل المواد. يظهر في كل خانة عدد الطلاب المكتملين واسم المدرس، ويفتح الكشف بالضغط عليها.

## الخصوصية والصلاحيات

- لكل شعبة ومادة **مدرس واحد فقط**، وهذا قيد في قاعدة البيانات نفسها. المدرس لا يفتح إلا كشوفه، وأي محاولة لفتح كشف غيره ترجع خطأ 403.
- **عند نقل كشف من مدرس لآخر** يرى المدرس الجديد درجات ذلك الكشف، لأنها درجات الشعبة نفسها.
- **حذف مدرس أو طالب** لا يحذف الدرجات المرصودة.
- **محاولات الدخول** محدودة بخمس محاولات خاطئة في الدقيقة.

## النشر على استضافة

1. وجّه الدومين إلى مجلد `public`.
2. اضبط `APP_ENV=production` و`APP_DEBUG=false` و`APP_URL`.
3. شغّل:

```bash
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

## التطبيق على الجوال (PWA)

عند أول فتح للموقع من الجوال تظهر رسالة أسفل الشاشة لإضافة «رصد الدرجات» إلى الشاشة الرئيسية:

| الجهاز | ما يظهر |
|---|---|
| أندرويد (Chrome / Samsung / Edge) | زر «تثبيت التطبيق» يثبّته مباشرة |
| آيفون (Safari) | خطوات: زر المشاركة ثم «إضافة إلى الشاشة الرئيسية» |
| متصفح آخر | الطريقة اليدوية من قائمة المتصفح |

- **«لاحقاً»:** يخفي الرسالة أسبوعاً.
- **بعد التثبيت:** لا تظهر الرسالة مرة أخرى.
- **على الكمبيوتر:** لا تظهر الرسالة.

**شرطان لظهور زر التثبيت:**
1. **الموقع يعمل على HTTPS.** على الإنترنت فعّل شهادة SSL (مثل Let's Encrypt المجانية من لوحة الاستضافة). عبر `http://192.168.x.x` على شبكة المدرسة لا يظهر زر التثبيت في أندرويد، وتظهر الطريقة اليدوية بدلاً منه.
2. **الموقع على جذر الدومين.** مثلاً `https://grades.example.com`، وليس داخل مجلد فرعي.

صفحات الدرجات لا تُحفظ على الجوال، فالرصد يحتاج اتصالاً بالإنترنت دائماً. عند انقطاع الاتصال تظهر صفحة «لا يوجد اتصال».

## المستخدمون والصلاحيات

من قائمة **«المستخدمون والصلاحيات»**، وهي ظاهرة للمدير العام فقط، تضيف حسابات الإدارة:

| نوع الحساب | ما يستطيعه |
|---|---|
| **مدير عام** | كل شيء، ومنه إضافة المستخدمين وتحديد صلاحياتهم |
| **مدير أو موظف** | الأقسام المحددة له فقط، ولكل قسم: بدون / مشاهدة فقط / مشاهدة وتعديل |
| **مدرس** | يُضاف من صفحة «المدرسون»، ويرى كشوفه فقط |

الأقسام التي تُحدَّد لها الصلاحيات:

| القسم | مشاهدة | تعديل |
|---|---|---|
| متابعة الرصد والدرجات | نسبة الرصد، وكل الكشوف، وتنزيلها Excel | تصحيح الدرجات المرصودة |
| المدرسون | قائمة المدرسين وتكليفاتهم | إضافة المدرسين وتعديلهم وتكليفهم |
| الطلاب | البحث وعرض الطلاب | الإضافة والتعديل والنقل والاستيراد |
| الصفوف والشعب | عرض الشعب | إضافة الشعب وتعديلها وحذفها |
| المواد | عرض المواد | إضافة المواد وتعديلها |
| عناصر الدرجة | عرض العناصر | تغيير العناصر ودرجاتها العظمى |

- القسم غير المسموح به يختفي من القائمة، ومحاولة فتح رابطه مباشرة ترجع خطأ 403.
- في وضع المشاهدة تختفي أزرار الإضافة والتعديل والحذف، وتظهر عبارة «صلاحيتك في هذا القسم: مشاهدة فقط».
- النظام لا يسمح بحذف آخر مدير عام أو إيقافه، ولا يسمح للمستخدم بإيقاف حسابه أو حذفه بنفسه.

**التحديث على الاستضافة:** ارفع الملفات، ثم شغّل:

```bash
php artisan migrate --force
php artisan view:clear
php artisan route:clear
php artisan config:cache
```

## بوابة الطلاب

- **رابط دخول الطلاب:** `https://دومينك/student/login`. يدخل الطالب برقم هويته وكلمة مرور.
- **إدارتها:** من قسم «بوابة الطلاب» في لوحة الإدارة. يحتاج الموظف صلاحية «بوابة الطلاب»، والمدير العام يملكها تلقائياً.

**خطوات التشغيل:**
1. **إنشاء الحسابات:** بجانب كل شعبة زر «إنشاء للجدد». يُنزّل ملف Excel فيه لكل طالب رقم الهوية وكلمة مرور مؤقتة من 6 أرقام، ورسالة جاهزة لولي الأمر فيها الرابط والبيانات. انسخ الرسالة وأرسلها عبر واتساب. **كلمات المرور تظهر في هذا الملف فقط**، فهي محفوظة مشفّرة في النظام.
2. **أول دخول:** يُطلب من الطالب اختيار كلمة مرور جديدة قبل أن يرى أي شيء، ويستطيع تغييرها لاحقاً من «كلمة المرور».
3. **نشر الدرجات:** اكتب عنوان النتائج (مثل «نتائج الفصل الدراسي الأول») واختر «نشر». قبل النشر يرى الطالب رسالة «لم تُنشر الدرجات بعد».
4. **ما يراه الطالب:**
   - المعدل العام وتقديره.
   - بطاقة لكل مادة فيها المجموع والنسبة والتقدير وشريط التحصيل.
   - جدول تفصيلي بكل عنصر درجة.
   - المادة غير المكتملة تظهر «قيد الرصد»، ولا تدخل في حساب المعدل.

**التقديرات:**

| التقدير | النسبة |
|---|---|
| ممتاز | 90 فأعلى |
| جيد جداً | 80 – 89 |
| جيد | 65 – 79 |
| مقبول | 50 – 64 |
| يحتاج إلى متابعة | أقل من 50 |

**ملاحظات:**
- **نسيان كلمة المرور:** من صفحة الشعبة اضغط «إعادة تعيين كلمة المرور» بجانب الطالب، فيُنزّل ملف فيه كلمة مؤقتة جديدة.
- **الطالب بدون رقم هوية** لا يمكن إنشاء حساب له. الصفحة تعرض عددهم، وتضيف رقم الهوية من صفحة «الطلاب».
- **محاولات الدخول** محدودة بخمس محاولات خاطئة في الدقيقة لكل رقم هوية.
- **التطبيق المثبّت على الجوال** يفتح على آخر بوابة استُخدمت على الجهاز: بوابة الطالب أو بوابة المدرسين.

**التحديث على الاستضافة:**

```bash
php artisan migrate --force
php artisan view:clear
php artisan route:clear
php artisan config:cache
```


## استيراد الطلاب وتحديثهم من Excel

من **الطلاب ← استيراد من Excel** ارفع كشف المدرسة كما هو.

1. **معاينة:** لا يُحفظ شيء في هذه الخطوة. تظهر لك:
   - الطلاب الجدد.
   - الطلاب الموجودون الذين صُحّح اسمهم أو رقم هويتهم.
   - من سيُنقل إلى شعبة أخرى.
   - من سيُوقف.
   - ملاحظات على الملف، مثل جنس غير مسجّل أو رقم هوية غير صحيح.
2. **تأكيد الاستيراد:** يطبّق التغييرات.

**كيف يتعرّف النظام على الطالب الموجود:** يبحث برقم الهوية أولاً، ثم بالاسم الكامل في نفس الصف، ثم بالاسم الأول واسم العائلة في نفس الصف. بهذه الطريقة يتعرّف على من أُكمل اسمه أو صُحّح رقم هويته، فلا يتكرر الطالب ولا تضيع درجاته.

**خيار «الملف هو الكشف الكامل للمدرسة»:** يوقف الطلاب الموجودين في النظام وغير الموجودين في الملف. تبقى درجاتهم محفوظة، ويمكن إعادتهم.


## رصد الدرجات من الإدارة

- **من أين:** قائمة **«رصد الدرجات»** تظهر لمن يملك صلاحية «متابعة الرصد والدرجات: تعديل».
- **الخطوات:** اختر المدرس، ثم كشفه، ثم ارصد الدرجات بنفس طريقة المدرس. كل درجة تُحفظ تلقائياً ويُسجَّل أنها رُصدت من حسابك.
- **رابط مختصر:** في صفحة «الشعب والمواد» لأي مدرس يوجد زر **«رصد درجاته»**.

## كلمة مرور الطالب من الإدارة

من **بوابة الطلاب** افتح الشعبة، وبجانب كل طالب خياران:
- **كلمة عشوائية جديدة:** تُنزّل في ملف Excel مع رسالة جاهزة لولي الأمر.
- **تعيين كلمة مرور محددة:** تكتبها بنفسك، وتختار هل يُطلب من الطالب تغييرها عند الدخول.

## ملاحظات المدرس للطالب

- **من الكشف:** في كشف المدرس عمود **«✎ ملاحظة»** بجانب كل طالب. يختار المدرس النوع (إشادة / ملاحظة / تنبيه) ويكتب النص، فتظهر فوراً في بوابة الطالب تحت عنوان «رسائل من مدرسيك».
- **صفحة «ملاحظات الطلاب»:** في الكشف نفسه، تعرض كل ما أرسله المدرس، ويحذف منها ما يريد.
- **النشر:** الملاحظات تظهر للطالب حتى لو لم تُنشر الدرجات بعد.

## بيانات دخول الطلاب

في **بوابة الطلاب ← الشعبة** يظهر لكل طالب:
- اسم المستخدم (رقم الهوية).
- كلمة المرور المؤقتة: مخفية، وتظهر بزر «إظهار».
- زر **«نسخ الرسالة»**: ينسخ رسالة جاهزة لولي الأمر.
- زر **«تعديل كلمة المرور»**.

بعد أن يختار الطالب كلمة مروره الخاصة تُحفظ مشفّرة، ولا يراها أحد، ولا الإدارة. إن نسيها تعيّن له الإدارة كلمة جديدة.

**كلمات المرور المؤقتة القديمة:** التي أُنشئت قبل هذا التحديث لا يمكن إظهارها، لأنها كانت محفوظة مشفّرة فقط. أعد إنشاءها إن احتجت رؤيتها.

## الاختبارات الإلكترونية

**عند المدرس** (قائمة «الاختبارات»):
1. **إنشاء اختبار لأحد كشوفه:**
   - العنوان والتعليمات.
   - وقت الفتح والإغلاق.
   - مدة الحل بالدقائق.
   - هل يرى الطالب الإجابات الصحيحة بعد التسليم.
2. **الأسئلة:**
   - اختيار من متعدد (من 2 إلى 6 خيارات)، أو صح وخطأ.
   - لكل سؤال درجة.
   - يمكن ترتيب الأسئلة وحذفها.
3. **النشر:** فعّل «نشر الاختبار للطلاب».
4. **النتائج:**
   - حالة كل طالب، ودرجته، ووقت تسليمه.
   - المتوسط، وأعلى درجة، وأقل درجة.
   - نسبة الإجابة الصحيحة لكل سؤال، لمعرفة الأسئلة الصعبة.
5. **نقل النتائج إلى الكشف:** تُحوَّل الدرجة بالتناسب إلى عنصر درجة تختاره، مثل المشاركة، لأقرب نصف درجة.
6. **قفل الأسئلة:** بعد أن يبدأ أول طالب الحل، لا يمكن تعديل الأسئلة، حفاظاً على عدالة التصحيح.

**عند الطالب** (قسم «اختباراتي» في بوابته):
- **بطاقة لكل اختبار:** متاح، أو لم يبدأ، أو تم التسليم مع الدرجة.
- **أثناء الحل:**
  - مؤقت تنازلي، ويُسلَّم الاختبار تلقائياً عند انتهاء الوقت.
  - عدّاد للأسئلة المجاب عنها.
  - حفظ الإجابات على الجهاز حتى لا تضيع إن حدّث الصفحة.
- **التسليم:** مرة واحدة فقط، ويُصحَّح فوراً.
- **بعد التسليم:** يرى درجته ونسبته ورسالة تشجيع، ومراجعة الإجابات إن سمح المدرس.

**التحديث على الاستضافة:**

```bash
php artisan migrate --force
php artisan route:clear
php artisan view:clear
php artisan config:cache
```

## الاختبارات: الإصدار الثاني

**أنواع الأسئلة:**

| النوع | التصحيح |
|---|---|
| اختيار من متعدد | تلقائي |
| صح أو خطأ | تلقائي |
| إجابة رقمية (قيمة + هامش خطأ + وحدة) | تلقائي، ويقبل 9.8 و٩٫٨ و1/2 و3×10^8 |
| إجابة نصية | تلقائي إن طابقت إحدى «الإجابات المقبولة»، وإلا يصححها المدرس يدوياً |

**المعادلات والصيغ والصور:** فوق كل سؤال شريط أدوات:
- **∑ معادلة:** محرر مرئي، فيه أزرار رياضيات (كسر، أس، جذر، تكامل…) وفيزياء (قوانين جاهزة، متجهات، وحدات) ورموز يونانية.
- **⚗ صيغة كيميائية:** يكتب المدرس `C6H12O6 + 6O2 -> 6CO2 + 6H2O` فتظهر بأرقام صغيرة وأسهم.
- **🖼 صورة:** حتى 4 ميغابايت، وتُحفظ في `public/uploads/quizzes`.
- **رموز سريعة:** × ÷ ± √ ² π ° → Δ ≤ ≥.
- **معاينة حية:** تُظهر السؤال كما يراه الطالب.

المعادلات تُكتب داخل النص بين علامتي `$…$`، ويعرضها الموقع بخط رياضي واضح.

**التصحيح ونشر النتائج:**
- **صفحة «النتائج والتصحيح»:** فيها زر **«نشر النتائج للطلاب / إخفاؤها»**. قبل النشر يرى الطالب «تم التسليم ✓» فقط.
- **التصحيح اليدوي:**
  - المحاولات التي فيها إجابات نصية تظهر «بانتظار التصحيح».
  - صفحة التصحيح تعرض إجابة الطالب بجانب نموذج الإجابة.
  - المدرس يكتب الدرجة، أو يضغط «كاملة» أو «صفر».
  - زر «حفظ والانتقال للطالب التالي» ينقله مباشرة للمحاولة التالية.
- **صعوبة الأسئلة:** متوسط درجة كل سؤال.

**الإدارة:** صلاحية جديدة اسمها **«الاختبارات الإلكترونية»**:
- **مشاهدة:** كل الاختبارات ونتائجها.
- **تعديل:** إنشاء اختبار لأي كشف نيابة عن المدرس، والتصحيح، ونشر النتائج.

## إيقاف حساب الطالب

من **بوابة الطلاب ← الشعبة ← «إيقاف الحساب»**، مع كتابة السبب.
- **عند الطالب:** يرى بعد الدخول صفحة «حسابك في البوابة موقوف حالياً» مع السبب وتاريخ الإيقاف، ولا يصل إلى درجاته ولا اختباراته.
- **عند الإدارة:** في أعلى صفحة البوابة قائمة بالحسابات الموقوفة، مع زر «إعادة التفعيل».

**التحديث على الاستضافة:**

```bash
php artisan migrate --force
php artisan route:clear
php artisan view:clear
php artisan config:cache
chmod 755 public/uploads public/uploads/quizzes
```

## أرقام الجوال

- **حقلان لكل طالب:** «الجوال» و«الجوال الإضافي»، بصيغة 05xxxxxxxx.
- **الاستيراد من Excel:** يقرأ عمود «رقم الجوال» وينظّفه تلقائياً:
  - 599123456 و+970599123456 و٠٥٩٩١٢٣٤٥٦ تصبح كلها 0599123456.
  - الخانة التي فيها رقمان مثل «0599…/0567…» يُحفظ منها رقمان.
  - الرقم الناقص أو الزائد يظهر في ملاحظات المعاينة.
  - الخانة الفارغة لا تمسح رقماً محفوظاً.
- **صفحة الطلاب:** عمود الجوال مع زر «واتساب»، والبحث بالجوال، وتعديل الجوال من «تعديل».
- **بوابة الطلاب:** زر **«إرسال واتساب»** يفتح محادثة ولي الأمر ومعها رسالة بيانات الدخول جاهزة، فيكفي الضغط على «إرسال».
- **ملف Excel لكلمات المرور:** فيه عمودان جديدان: «الجوال»، ورابط «إرسال» على واتساب لكل طالب.

**إضافة الأرقام للطلاب الموجودين بأمر واحد:**

```bash
php artisan school:sync-phones                  # من الأرقام المرفقة مع المشروع (842 رقماً)
php artisan school:sync-phones كشف.xlsx         # أو من ملف Excel جديد
php artisan school:sync-phones كشف.xlsx --overwrite   # مع استبدال الأرقام المحفوظة
```
يطابق الأمر الطالب برقم الهوية ثم بالاسم، ولا يغيّر أي بيانات أخرى.

## اعتماد الدرجات

قائمة **«اعتماد الدرجات»** تظهر لمن يملك صلاحية «اعتماد الدرجات». المدير العام يملكها تلقائياً.

**ما تعرضه الصفحة:** جدول فيه كل كشف (مادة × شعبة × مدرس) مقابل عناصر الدرجة. في كل خانة:
- حالتها: 🔒 معتمد، أو غير معتمد.
- عدد الدرجات المرصودة، مثل «مرصود 24/26».
- من اعتمدها ومتى.

**طرق الاعتماد وفكه:**

| المطلوب | الطريقة |
|---|---|
| خانة واحدة (مثل الشهري الأول لرياضيات السابع إناث) | حدّد الخانة، ثم «اعتماد المحدد» |
| عنصر في كل الكشوف (مثل الشهري الأول لكل المدرسة) | «اعتماد جماعي»: أبقِ علامة العنصر وحده، ثم «اعتماد» |
| كشف كامل | «تحديد الكشف» في سطره، ثم «اعتماد المحدد» |
| عمود في الكشوف المعروضة | «تحديد العمود» في رأسه، ثم «اعتماد المحدد» |
| كل الدرجات | «اعتماد جماعي» مع تحديد كل العناصر |
| لصف أو مادة أو مدرس معيّن | صفِّ الجدول أولاً، ثم استخدم الاعتماد الجماعي |

فك الاعتماد بنفس الطرق، بزر **🔓 فك الاعتماد**.

**ماذا يحدث بعد الاعتماد:**
- **في كشف المدرس:** يظهر العمود المعتمد مع 🔒، وخاناته مقفلة، وتظهر رسالة توضح ذلك. باقي الأعمدة يرصدها المدرس كالمعتاد.
- **على الخادم:** يرفض أي محاولة لتعديل درجة معتمدة، من المدرس أو من الإدارة، حتى يُفك اعتمادها.
- **نقل نتائج اختبار:** لا يمكن نقلها إلى عنصر معتمد.
- **بطاقة الكشف:** في صفحة «كشوفي» للمدرس تظهر «🔒 كل الدرجات معتمدة» أو «معتمد 2 من 4 عناصر».
- **متابعة الرصد:** تظهر 🔒 بجانب الكشوف المعتمدة.

**التحديث على الاستضافة:**

```bash
php artisan migrate --force
php artisan route:clear
php artisan view:clear
php artisan config:cache
```

## بيانات دخول الطلاب

من **بوابة الطلاب ← «بيانات دخول الطلاب»** تفتح صفحة فيها كل الطلاب.

**ما تعرضه الصفحة لكل طالب:**
- الاسم والشعبة.
- اسم المستخدم (رقم الهوية).
- كلمة المرور: مخفية، وتظهر بزر «إظهار».
- الجوال.

**التصفية والبحث:**
- حسب الصف أو الشعبة.
- حسب حالة الحساب: كلمة مؤقتة ظاهرة، أو اختار الطالب كلمته الخاصة، أو بدون حساب.
- بحث بالاسم أو الهوية أو الجوال.

**الأزرار لكل طالب:**
- **«تغيير كلمة المرور»:** نافذة فيها كلمة مقترحة من 6 أرقام، أو تكتب أنت الكلمة، مع خيار «يطلب من الطالب تغييرها عند أول دخول».
- **«واتساب» و«نسخ»:** رسالة بيانات الدخول جاهزة لولي الأمر.

**أزرار الصفحة:**
- **«⬇ تنزيل الملف (Excel)»:** بيانات الدخول الحالية للقائمة المعروضة، دون إنشاء كلمات جديدة.
- **«🖨 طباعة بطاقات الدخول»:** بطاقات صغيرة، بطاقتان في كل صف، تُقص وتُوزَّع على الطلاب. في كل بطاقة الشعار والاسم والهوية وكلمة المرور والرابط.

كلمة المرور التي اختارها الطالب بنفسه لا تظهر، لأنها محفوظة مشفّرة. للطالب الذي نسيها عيّن كلمة جديدة.

## مدرسو الطالب (واتساب)

في بوابة الطالب قسم **«مدرسيّ»**، يعرض **مدرسي شعبته فقط**. لكل مدرس اسمه وموادّه وزر **«واتساب»** يفتح محادثة معه ومعها رسالة جاهزة: «السلام عليكم أستاذ/ة… أنا الطالب/ة… من شعبة…».

**التحكم من الإدارة:**
- **الرقم:** يُكتب في **المدرسون ← تعديل**، في خانة «رقم الجوال / واتساب».
- **الإخفاء:** خيار **«إظهار رقمه لطلابه»** مفعّل افتراضياً. إن ألغيته يظهر بدل الزر «التواصل عبر المدرسة».

**التحديث على الاستضافة:**

```bash
php artisan migrate --force
php artisan route:clear
php artisan view:clear
php artisan config:cache
```
